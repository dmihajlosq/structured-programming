# Structured Programming – University Exercises

This repository contains practical programming exercises completed as part of the Structured Programming course at the Faculty of Computer Science and Engineering (FINKI).

All exercises are implemented in **C++**, using the structured programming paradigm. Unlike Object-Oriented Programming, these assignments focus on writing complete programs from scratch without using classes or objects.

### How the Exercises Work
For each assignment, the problem statement is provided, and the task is to develop the entire program independently, from the initial `main()` function to all required functions and logic.

### What is included?
- Complete C++ programs written from scratch.
- Solutions to various programming problems.
- Function implementation and modular programming.
- Algorithms and problem-solving approaches.

### Main Topics
- Variables and Data Types
- Conditional Statements and Loops
- Functions
- Arrays and Matrices
- Strings
- Pointers
- Recursion
- Basic Algorithms and Problem Solving

### Technologies
- C++
- Structured Programming
